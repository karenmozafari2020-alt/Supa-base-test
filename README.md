# Karen Messenger V4.1 Remote

نسخه آماده برای اجرای Termux و Deploy روی یک سرویس عمومی.

## Termux
cd ~/storage/downloads/"Karen Messenger V4.1"
npm install
npm start

محلی:
http://127.0.0.1:3000

## اتصال از راه دور
برای اتصال از اینترنت، برنامه باید روی یک سرور/سرویس عمومی Deploy شود. IP محلی 192.168.x.x فقط داخل شبکه محلی کار می‌کند.

این پروژه `render.yaml` دارد و برای Deploy روی سرویس‌های سازگار آماده است. بعد از Deploy، URL عمومی سرویس را به دوستان بده.

Cloudflare Tunnel برای اجرای این نسخه الزامی نیست.
